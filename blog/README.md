# Project blog (drafts)

One post per milestone, in the owner's first person.

- File name `YYYY-MM-DD-slug.md`, front matter `title`, `date`, `draft: true`, `tags`.
- A session drafts; the owner edits and publishes. A session never flips `draft`.
- Say what was learned, including what went wrong.
- Vendor and format facts get a link.
- No personal data and no customer data: no names of customers or friends, no private numbers, no customer files or renders of them.
- Screenshots stay under `field/…/screenshots/` until published.
